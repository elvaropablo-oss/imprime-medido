# Fuentes y comparación

- CSS Values and Units, W3C: relación normativa entre unidades físicas CSS. https://www.w3.org/TR/css-values-4/#absolute-lengths
- GridPrint FAQ: tamaño físico, división en mosaicos, formatos y procesamiento local. https://gridprint.app/en/faq
- Avery Design & Print: flujo basado en plantillas y exportación a PDF. https://www.avery.com/help/article/create-and-print-labels-and-other-projects-in-design-and-print-online
- Printsheet calibration: uso de una regla y cuadrado de control antes de imprimir a medida. https://printsheet.io/calibration/

ImprimeMedido V1 se limita a geometría sencilla y corrección comprobable. No afirma que las unidades CSS garanticen por sí solas una salida física exacta.
