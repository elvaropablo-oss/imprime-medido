# ImprimeMedido

Herramientas estáticas para calibrar una impresora, preparar hojas de etiquetas y generar rectángulos con dimensiones físicas verificables.

## Desarrollo

- `npm run verify`: comprueba sintaxis, genera la web, ejecuta pruebas y valida referencias.
- `npm run serve`: sirve `dist/` para pruebas locales.

La web funciona sin backend y está preparada para GitHub Pages bajo `/imprime-medido/`.
